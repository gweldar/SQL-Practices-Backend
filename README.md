#Advanced SQL & Data Analytics for Backend Engineering

This repository contains a collection of complex SQL queries, relational data modeling challenges, and business intelligence analytical scripts designed to prepare for scalable backend architectures.

##Key Concepts Mastered

1. Relational Joins & Schema Traversal
- Multi-table `INNER JOIN`s connecting up to 5 relational tables in chain.
- Entity-relationship mapping through primary (`PK`) and foreign keys (`FK`).

2. Aggregations & Grouping
- Advanced usage of `GROUP BY` and `HAVING` clauses for business metrics.
- Summary functions (`SUM`, `AVG`, `COUNT`, `MAX`, `MIN`).

3. Complex Subqueries
- Uncorrelated and correlated subqueries within `WHERE` and `FROM` clauses.
- Business filtering logic utilizing `IN` and `NOT IN` operators.

4. Window Functions & Analytics
- Data windowing using `OVER()` and partition resets via `PARTITION BY`.
- Ranking techniques: `ROW_NUMBER()`, `RANK()`, and `DENSE_RANK()`.
- Filtered windowing through derived tables (subqueries applied to window results).

Tools Used
- MySQL
- DBeaver
